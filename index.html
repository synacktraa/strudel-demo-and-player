Welcome

Welcome to this hands-on Strudel workshop! You'll learn to create music by writing and modifying code in real-time. Each cell below contains editable code that you can play, stop, and experiment with.

What is Strudel?

Strudel is a live-coding environment for making patterns and music in the browser. It's based on the TidalCycles pattern language and runs entirely in your web browser with no installation required.

Learn more at strudel.cc

How to Play and Stop the Code

  • Each code cell has Play button at the top
  • Click inside any cell to edit the code, then press Play to hear your changes
  • You can play multiple cells at once to layer sounds
  • Note: Browsers require a user interaction before audio can start, so you'll need to click Play first

Cell 2: Pattern Repetition

Cell 5: Layering

Objective: Combine multiple patterns using stack()
