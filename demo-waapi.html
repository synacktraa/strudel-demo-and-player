Web Animations API (WAAPI) Demonstrations

The Web Animations API provides JavaScript control over CSS animations with hardware acceleration. These examples show how to use WAAPI instead of CSS keyframes or JavaScript libraries.

1. Basic Scale Animation (Button Press Feedback)

Click Me
element.animate([
  { transform: 'scale(1)' },
  { transform: 'scale(0.95)' },
  { transform: 'scale(1)' }
], {
  duration: 160,
  easing: 'cubic-bezier(0.23, 1, 0.32, 1)'
});

Hardware-accelerated scale animation using strong ease-out curve. Perfect for button press feedback.

2. Fade In with Scale (Cell Entry)

I fade in!
element.animate([
  { opacity: 0, transform: 'translateY(12px)' },
  { opacity: 1, transform: 'translateY(0)' }
], {
  duration: 400,
  fill: 'forwards',
  easing: 'cubic-bezier(0.23, 1, 0.32, 1)'
});

Using fill: 'forwards' to persist the final state. Good for entry animations.

3. Sequential Stagger Animation

const items = document.querySelectorAll('.item');
items.forEach((item, index) => {
  item.animate([
    { opacity: 0, transform: 'translateY(8px)' },
    { opacity: 1, transform: 'translateY(0)' }
  ], {
    duration: 300,
    delay: index * 60,
    fill: 'forwards',
    easing: 'cubic-bezier(0.23, 1, 0.32, 1)'
  });
});

Stagger animations by applying incremental delays. Each element animates 60ms after the previous.

4. Clip-Path Reveal Animation

Revealed from bottom
element.animate([
  { clipPath: 'inset(0 0 100% 0)' },
  { clipPath: 'inset(0 0 0 0)' }
], {
  duration: 600,
  fill: 'forwards',
  easing: 'cubic-bezier(0.77, 0, 0.175, 1)'
});

Using clip-path for reveals. The inset values: top, right, bottom, left. This "eats" from bottom (100%) to nothing (0%).

5. Interruptible Animation

Hover Me
let currentAnimation = null;

element.addEventListener('mouseenter', () => {
  if (currentAnimation) currentAnimation.cancel();
  currentAnimation = element.animate([
    { transform: 'scale(1.2)' }
  ], {
    duration: 200,
    fill: 'forwards',
    easing: 'cubic-bezier(0.23, 1, 0.32, 1)'
  });
});

element.addEventListener('mouseleave', () => {
  if (currentAnimation) currentAnimation.cancel();
  currentAnimation = element.animate([
    { transform: 'scale(1)' }
  ], {
    duration: 200,
    fill: 'forwards',
    easing: 'cubic-bezier(0.23, 1, 0.32, 1)'
  });
});

Canceling previous animations before starting new ones. This prevents animation conflicts and feels smooth.

6. Blur Transition (State Change)

State A
// Blur out
element.animate([
  { filter: 'blur(0px)', opacity: 1 },
  { filter: 'blur(4px)', opacity: 0.7 }
], {
  duration: 100,
  fill: 'forwards',
  easing: 'ease'
});

// Change content, then blur in
setTimeout(() => {
  element.textContent = 'State B';
  element.animate([
    { filter: 'blur(4px)', opacity: 0.7 },
    { filter: 'blur(0px)', opacity: 1 }
  ], {
    duration: 100,
    fill: 'forwards',
    easing: 'ease'
  });
}, 100);

Using blur to mask imperfect transitions. Blur bridges the visual gap between two states.

7. Multiple Properties (Nav Indicator)

element.animate([
  { transform: 'scaleX(0) translateX(0)' },
  { transform: 'scaleX(1) translateX(0)' }
], {
  duration: 180,
  fill: 'forwards',
  easing: 'cubic-bezier(0.23, 1, 0.32, 1)'
});

Combining multiple transform values in a single property. Better performance than animating separately.

Key Advantages of WAAPI

  • Hardware-accelerated: Runs on GPU, same as CSS animations
  • JavaScript control: Can cancel, reverse, pause, or speed up mid-animation
  • No CSS keyframes needed: Keep animation logic in JS when appropriate
  • No library required: Native browser API with excellent support
  • Better than RAF loops: Automatic optimization and throttling
  • Interruptible: Call .cancel() to stop and start new animations smoothly
